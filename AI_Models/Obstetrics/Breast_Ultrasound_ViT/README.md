# Breast Ultrasound ViT

Three-class breast ultrasound classifier from `hugging-science/breast-cancer-detector-2`.

- Checkpoint directory: `checkpoint/`
- Input: PNG/JPG/JPEG breast ultrasound image
- Classes: benign, malignant, normal
- Output: DataFrame with the predicted class and all softmax probabilities

Research use only; not a medical device or standalone clinical diagnosis.
