# Cervical Cytology SIPaKMeD

AlexNet model from `hp1318/alexnet-finetuned-sipakmed` for single-cell Pap-smear morphology classification.

- Checkpoint: `checkpoint/best_alexnet.pth`
- Labels: `checkpoint/labels.json`
- Input: cropped cell image in PNG/JPG/JPEG format
- Classes: Superficial-Intermediate, Parabasal, Koilocytotic, Dyskeratotic, Metaplastic

This is single-cell morphology classification, not patient-level cervical cancer diagnosis. Research use only.
