# LC25000 Colon ViT

Binary colon histopathology classifier using `1aurent/vit_base_patch16_224.owkin_pancancer_ft_lc25000_colon`.

- Checkpoint directory: `checkpoint/`
- Input: H&E histopathology tile in PNG/JPG/JPEG format
- Classes: benign colon tissue, colon adenocarcinoma
- Output: DataFrame with both softmax probabilities
